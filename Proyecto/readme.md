# YakuToring — módulos del prototipo

Esta carpeta reúne los archivos de trabajo del prototipo del Equipo 09. La documentación distingue lo probado de lo que aún está en desarrollo.

- [Módulo electrónico](Modulo%20Electronico/readme.md): placas, sensores, energía y conexiones.

**Estado:** desarrollo experimental. Los esquemas, modelos, piezas y programas que se incorporen deberán verificarse antes de presentarse como versiones finales. Véase también el [README principal](../README.md).
