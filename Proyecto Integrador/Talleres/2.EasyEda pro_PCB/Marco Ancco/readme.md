# PCB para monitoreo de calidad del agua

Placa para conectar sensores de conductividad eléctrica, temperatura del agua y pH.

## Sensores utilizados

- **Sensor de conductividad:** mide la conductividad eléctrica del agua.
- **Sensor de temperatura del agua:** mide la temperatura del agua.
- **Sensor de pH:** mide la acidez o alcalinidad del agua.
