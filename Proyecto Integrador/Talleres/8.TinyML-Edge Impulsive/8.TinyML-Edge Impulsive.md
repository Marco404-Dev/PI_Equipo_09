# **TinyML-Edge Impulsive**



**Proyecto**  
---

El presente proyecto consistió en desarrollar un sistema de detección y reconocimiento de dos objetos cotidianos: un llavero y un corrector. Para ello, se utilizó el dispositivo XIAO ESP32S3 para entrenar un modelo de inteligencia artificial que permita identificar y distinguir los objetos mencionados mediante imágenes.

**Pruebas estadísticas**  
---

Se observó que el modelo alcanzó una precisión del 93,8 % y una pérdida de 0,10. En la matriz de confusión, el corrector se clasificó a la perfección (100 %), mientras que el llavero registró un 83,3 %. Estos resultados indican que el modelo presenta un buen desempeño, aunque todavía se debe la identificación del llavero.

La matriz de confusión muestra una clasificación correcta del 100 % para el corrector y el llavero. Además, las pruebas con los datos de test finalizaron satisfactoriamente, lo que evidencia un buen desempeño con las muestras evaluadas.
