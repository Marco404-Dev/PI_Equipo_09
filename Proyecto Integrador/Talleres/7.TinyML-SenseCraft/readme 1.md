# Prueba de un modelo de detección de género con SenseCraft AI

## 1. Objetivo

Abrir un modelo de detección de género en **SenseCraft AI** y realizar una prueba con **tres integrantes**, registrando los resultados obtenidos.

> **Nota:** El modelo genera una clasificación estimada a partir de la imagen. Su predicción no determina la identidad de género de una persona y puede presentar errores.

## 2. Plataforma utilizada

- **Plataforma:** [SenseCraft AI](https://sensecraft.seeed.cc/ai/model)
- **Modelo:** Detección o clasificación de género
- **Prueba:** Captura mediante cámara y observación de la predicción del modelo
- **Participantes previstos:** 3 integrantes
