## Reflexion
En este trabajo se utilizaron dos métodos: la **Regresión Lineal** y el **Árbol de Decisión**. La principal diferencia es la forma en la que cada uno analiza los datos. La regresión lineal busca una relación más directa entre las variables para realizar la predicción, mientras que el árbol de decisión divide los datos según diferentes condiciones. Por eso, aunque ambos modelos buscan predecir lo mismo, pueden llegar a resultados diferentes.

Considero que el gráfico más importante es el de **Valores reales vs. Valores predichos**, porque permite observar de manera sencilla qué tan cerca están las predicciones del modelo de los valores reales. Si ambos valores son parecidos, significa que el modelo está teniendo un buen desempeño. Además, este gráfico facilita comparar visualmente los resultados obtenidos con cada método y entender mejor cuál se ajusta a los datos.
